# PUMA Wiki

PUMA is a local-first benchmarking platform for open-weight Large Language Models
applied to ICT Project Management tasks — issue triage, story-point estimation,
and pairwise prioritization. It runs entirely on your hardware via
[Ollama](https://ollama.com), needs no external API account, and produces
reproducible results with a complete sustainability footprint for every run.
This Wiki is the user-facing reference for installing, running, interpreting,
and optionally publishing PUMA benchmarks.

## What's inside this Wiki

- [Installation](Installation) — getting PUMA running on Linux, macOS, and
  Windows via Docker.
- [Quick Start](Quick-Start) — your first benchmark in under five minutes.
- [Architecture](Architecture) — the six-layer modular design and how data
  flows through it.
- [Running Benchmarks](Running-Benchmarks) — exhaustive flag reference for
  `puma run`, scenario catalog, prompting strategies.
- [Models and Datasets](Models-And-Datasets) — curated model catalog,
  hardware profiles, dataset sources.
- [Metrics and Sustainability](Metrics-And-Sustainability) — the seven metric
  families and the carbon-footprint methodology.
- [Publishing Results](Publishing-Results) — submitting verified results to
  PUMA Community.
- [FAQ](FAQ) — common questions and quick answers.
