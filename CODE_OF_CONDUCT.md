# Code of Conduct

The PUMA project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All maintainers, contributors, and users of the
project are expected to abide by it.

## Reporting

Concerns about behaviour that violates the Code of Conduct can be
reported privately to `pumacapstoneproject@gmail.com`. Reports will
be reviewed by the maintainers in confidence and addressed promptly.

## Scope

The Code of Conduct applies to all project spaces — GitHub repository
discussions, issue trackers, Pull Request reviews, and any other forum
operated under the PUMA Project banner. It also applies when an
individual is officially representing the project in public spaces.
